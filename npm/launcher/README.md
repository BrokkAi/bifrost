# Bifrost

Bifrost gives code intelligence tools to agents, editors, and scripts.

Install the native CLI:

```sh
npm install -g @brokkai/bifrost
bifrost --version
```

For one run, use `npx -y @brokkai/bifrost --version`.

The package installs the native Bifrost release for the current platform. It
does not download a binary at first start. See
https://bifrost.brokk.ai/install/ for other installation methods.
