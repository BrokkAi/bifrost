# brokk-bifrost-mcp

Internal MCP host implementation for Bifrost. Part of [Bifrost](https://github.com/BrokkAi/bifrost).

This crate provides the bundled MCP server host used by the
[`brokk-bifrost`](https://crates.io/crates/brokk-bifrost) facade. It is an
internal implementation detail and offers no stability guarantees. Depend on
`brokk-bifrost` instead.
