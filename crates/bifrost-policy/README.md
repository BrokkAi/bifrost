# brokk-bifrost-policy

Versioned static-analysis policy support for Bifrost. Part of [Bifrost](https://github.com/BrokkAi/bifrost).

This crate provides the policy loading and evaluation used by the
[`brokk-bifrost`](https://crates.io/crates/brokk-bifrost) facade. It is an
internal implementation detail and offers no stability guarantees. Depend on
`brokk-bifrost` instead.
