# brokk-bifrost-analysis

Protocol-neutral analysis engine for Bifrost hosts and runtimes. Part of [Bifrost](https://github.com/BrokkAi/bifrost).

This crate is an internal implementation detail of the
[`brokk-bifrost`](https://crates.io/crates/brokk-bifrost) facade and offers no
stability guarantees. Depend on `brokk-bifrost` instead.
