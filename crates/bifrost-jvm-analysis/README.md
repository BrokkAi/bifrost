# brokk-bifrost-jvm-analysis

Java, Kotlin and Scala analyzers, their shared JVM source realm and artifact
integration, and language-specific usage resolution for Bifrost. This crate
builds on the shared analysis engine and JVM language knowledge; the tools
crate assembles its three language supports into the complete language table.

Internal implementation detail of `brokk-bifrost`; no stability guarantees.
Depend on `brokk-bifrost` for the product API.
