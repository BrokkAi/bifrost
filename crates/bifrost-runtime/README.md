# brokk-bifrost-runtime

Protocol-neutral runtime support for Bifrost. Part of [Bifrost](https://github.com/BrokkAi/bifrost).

This crate provides internal runtime plumbing for the
[`brokk-bifrost`](https://crates.io/crates/brokk-bifrost) facade. It offers no
stability guarantees. Depend on `brokk-bifrost` instead.
